Section 1

Search Scope

Every real AIAsset row in the live production database was queried directly and examined in full — 7 records, no sampling, no exclusions. For each asset, every related governance, evidence, authority, and action table was queried by that asset's real production-generated ID. mockData.ts, backend/prisma/seed.js, and browser localStorage were explicitly excluded as evidence sources — a record counts only if it exists as a row in the production database at query time.

Section 3

Workflow Pattern Required

T0 Governance State → Material Change → Evidence Available At T1 → Consequential Action → Resulting Governance Position

A workflow qualifies only if all five of the following exist as production database records for the same asset:

  • An approved asset or agent (T0 governance/decision state)
  • A real material change record
  • A real consequential action record
  • Real authority information
  • Real evidence records
